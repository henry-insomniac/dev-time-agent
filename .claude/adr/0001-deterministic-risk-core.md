# Keep the risk core deterministic

Dev Time generates Delivery Risks, priorities, lifecycle changes, and Risk Briefs from GitHub facts and explainable rules, without depending on an LLM or Agent. The Contextual Agent may explain evidence, answer follow-up questions, and draft remediation guidance, but it does not decide whether a risk exists; this trades some open-ended reasoning flexibility for a Risk Workspace that remains trustworthy, testable, and useful when AI services are unavailable.
